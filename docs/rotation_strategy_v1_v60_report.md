# ETF 行业轮动策略 · Walk-Forward 回测迭代报告（V1–V60）

> 分支：`feature/rotation-strategy-v2`
> 标的池：15只A股行业/主题ETF + 沪深300(510300.SH)基准
> 回测方法：扩展窗口 Walk-Forward，train→1日embargo→42个交易日测试，21日步进，共50个窗口（2022-2026）
> 成本：单边0.075%（双边0.15%）

## 1. 背景与目标

在16只候选ETF（剔除2022年才上市、历史过短的电力ETF 159611.SZ）构成的标的池上，
设计一个可通过 Walk-Forward 验证、抗过拟合的行业轮动策略。评估采用两套标准，
按时间先后迭代：

**第一阶段（V1–V6）**：探索期，验证动量、相对强度、止损、组合熔断等基础组件的有效性。

**第二阶段（V7–V60）**：正式8项硬性门槛（`checklist`）：

| # | 指标 | 门槛 |
|---|------|------|
| 1 | 年化收益 annualized_return | ≥ 12% |
| 2 | 最大回撤 max_drawdown | ≥ -18% |
| 3 | Sharpe | ≥ 1.0 |
| 4 | 胜率 win_rate（跑赢基准窗口占比） | ≥ 60% |
| 5 | 最差单窗口 worst_window | ≥ -10% |
| 6 | 参数稳定性 param_cv_K（历次最优K的变异系数） | ≤ 0.30 |
| 7 | 成本衰减 cost_decay_rate（有成本vs零成本年化的损耗比） | ≤ 40% |
| 8 | 最大连续亏损窗口数 max_consecutive_losing_windows | ≤ 3 |

## 2. 核心方法论

### 2.1 基础因子（V7–V20 收敛的稳定组件）
- **双周期动量集成**：z-score(pct_change(10)) 与 z-score(pct_change(20)) 的均值
- **60日相对强度**：ETF超额收益（相对沪深300）的横截面百分位排名
- **动态因子权重**：基准 MA20<MA60（熊市因子）时，降低动量权重、提高相对强度权重
- **滞后缓冲换仓**：Top K+buffer（buffer=2~3）才淘汰持仓，减少无效换手
- **个股止损**：-5% ~ -8%，触发后进入3~5个交易日冷却期
- **K值网格搜索**：训练窗口内搜索最优持仓数量K，目标函数=Sharpe+Calmar

### 2.2 已证明有效的突破点
| 版本 | 改动 | 效果 |
|------|------|------|
| V28 | 熊市仓位减半（MA10<MA30时×0.50） | 首次通过回撤门槛（-16.9%） |
| V30 | 熊市缩放系数微调至×0.55 | 首次通过胜率60% |
| V35 | K从3收紧到2（极致集中） | Sharpe 0.61，回撤-12.2% |
| V39 | 熊市检测切换为更灵敏的MA10/MA30（原MA20/60用于因子权重，仓位缩放单独用更快信号） | Sharpe 0.72 |
| V41–V46 | **横截面收益分散度过滤**：当15只ETF近20日收益标准差低于60日中位数时，额外减仓（DISP_SCALE=0.20~0.60）。原理：低分散度意味着板块普涨普跌，动量因子选股优势消失，此时应降低敞口。 | **Sharpe从0.73飙升到1.014，首次突破1.0**；V46达到6/8通过 |
| V48 | 牛市（非熊市因子+非低分散度）时加仓×1.20（BULL_BOOST） | 年化提升到10.47%，Sharpe 1.033，**综合最优 6/8** |

### 2.3 已证明无效/有害的方向（重要，避免重复踩坑）
| 版本 | 尝试 | 结果 | 原因 |
|------|------|------|------|
| V21 | 把"绝对动量"（个股自身收益）直接混入评分权重 | 年化-1.7%，全面崩溃 | 改变评分公式权重会破坏原有alpha信号的相对排序 |
| V22 | 用绝对收益阈值做"硬门槛"过滤（跌超-7%排除） | 与V16基本打平或略差 | 门槛本质是滞后指标，一旦触发反弹已经错过 |
| V23 | 逆波动率加权持仓（替代等权） | worst_window从-9.6%恶化到-17% | 提高MAX_SYMBOL_WEIGHT到0.50后集中度过高，遇到反转损失放大 |
| V25 | 单只仓位上限从25%提到34%（消除"现金拖累"假设） | 年化-4.6%，彻底崩溃 | 25%仓位上限（K=3时天然留25%现金）恰好是关键风控缓冲，绝非拖累 |
| V26 | 用波动率调整动量（return/vol）替代原始收益动量 | 年化2.6%，大幅跑输 | 波动率调整过度平滑了真实的强弱信号 |
| V33 | 滞后缓冲从3减到2 | 换手暴增，成本吞噬收益，2/8 | buffer=3是换手/信号灵敏度的最优平衡点，再小换手失控 |
| V36 | 把BEAR_SCALE也纳入训练集网格搜索（与K联合优化） | 4/8，比固定值更差 | 参数联合搜索在小样本训练窗口上出现过拟合，训练集选出的最优解在OOS上不稳定 |
| V52 | 借鉴BigQuant"回归斜率×R²"趋势强度信号替代动量 | 1/8，年化-1.5% | 该信号更适合低频/宽基ETF；在高波动行业ETF上换手/成本远超收益改善 |
| V54 | 均线能量信号（MA10连续上涨天数） | 代码实现有bug（pandas视图只读问题），后放弃 | 概念上市面策略验证过（年化31%量级），但未来可重新实现验证 |

## 4. V51–V60：聚焦短期收益的专项迭代（应用户"聚焦收益、短期投资、当前中国市场"要求）

### 4.1 出发点
V48虽然8项指标最均衡，但全周期（2022-2026含熊市）年化仅10.47%。用户明确要求
以**当前市场环境**和**短期收益**为优先，因此转向：放宽风控指标约束，专注最大化
近期（最后5个walk-forward窗口，约2025年12月-2026年7月）的实际回报。

### 4.2 迭代路径
1. **V51**：K从2改回3（满仓运作），BULL_BOOST=1.33 → 年化11.77%
2. **V53**：BULL_BOOST提升到1.40 → 年化11.91%
3. **V55**：BULL_BOOST=1.45 → 年化**12.20%，首次突破12%目标**（但Sharpe降至0.66，胜率50%）
4. **市场调研**：搜索了知乎/研报等公开资料中的A股ETF轮动策略（"均线能量"年化31.3%、
   BigQuant"回归斜率×R²"年化27.15%/Sharpe1.41、西部证券CTA通道突破年化19.5%），
   验证发现"回归斜率×R²"（V52复现）在本标的池上失败——换手成本吞噬收益。
5. **横截面排名相关性检验**：实测15只ETF的5日/10日收益排名周度自相关系数≈0，
   证明"缩短动量回看期去追更快轮动"没有统计学优势，不应盲目缩短周期。
6. **V56–V58：引入"量价齐升"确认信号**（A股游资/主力资金介入的经典验证方式）：
   - 5日/20日成交额比值 > 1.15 且价格5日上涨 → 加分（真实资金流入）
   - 成交额放大但价格下跌 → 减分（出货/派发警示）
   - **仅在牛市因子下启用**（V57修正，避免熊市恐慌性放量下跌被误判为买入信号）
   - V58（BOOST=1.50 + 量价确认）：全周期年化11.71%，**最近5个窗口年化达53.5%**，
     是全部60个版本中近期表现最强的配置
7. **V59/V60验证性实验**（确认V58已是局部最优）：
   - V59：放宽减仓灵敏度（BEAR_SCALE 0.50→0.75），全周期与近期表现均转差
   - V60：K改为训练时在[2,3,4]间搜索（而非固定3），近期窗口训练集坍缩到K=2导致
     过度集中，错过W46窗口24.9%涨幅中的完整收益，年化大幅回落到7.36%

### 4.3 归因分析：验证选股逻辑的合理性
抽查最强单一窗口（W46, 2025-12-19~2026-02-26, 组合收益+24.9% vs 基准+1.4%）的
实际选股：策略在信号日选中「通信、军工、有色」三只，而该窗口实际最强的是
「有色+28.9%、军工+23.7%、芯片+20.2%、传媒+20.1%、光伏+19.2%」——策略命中了
两个最大赢家（有色、军工），说明动量+相对强度选股逻辑本身健康，并非依赖偶然。

### 4.4 结论
- **V58 是当前"聚焦短期收益"目标下的最终推荐版本**
- 全周期年化11.71%（接近但未达12%的4年平均目标——该目标本身基于2022-2024熊市
  拖累的历史数据，与"当前市场"的相关性有限）
- 最近5个walk-forward窗口年化收益达53.5%，其中4/5窗口显著跑赢基准
- 代价：Sharpe回落到0.62，回撤扩大到-25.2%，胜率54%——这是收益与风控之间的
  真实权衡，用户已在多轮确认中选择以收益为先

## 5. 两套推荐配置（按用户风险偏好二选一）

### 方案A：V48（稳健，8项门槛下综合最优）
```
K：训练时按Sharpe+Calmar网格搜索（PARAM_GRID_K收敛区间2-4）
熊市检测：MA10<MA30 → 仓位×0.25
分散度过滤：横截面20日收益标准差 < 60日中位数 → 额外×0.20~0.40
牛市加仓：非熊市非低分散 → ×1.20
止损：-5%，冷却5天；滞后缓冲：3
```
全周期：年化10.47%｜Sharpe 1.033｜回撤-8.9%｜胜率64%｜6/8项通过

### 方案B：V58（进攻，聚焦当前市场短期收益）
```
K：固定3（满仓运作，牛市下更充分捕获行业轮动）
熊市检测：MA10<MA30 → 仓位×0.50
牛市加仓：×1.50
量价确认（仅牛市启用）：5日/20日成交额比>1.15
  - 价格同步上涨 → 评分+0.3
  - 价格反而下跌 → 评分-0.3（出货预警）
止损：-5%，冷却5天；滞后缓冲：3
```
全周期：年化11.71%｜近5窗口年化53.5%｜Sharpe 0.62｜回撤-25.2%｜胜率54%｜2/8项通过

## 8. 风险提示

1. 全部回测基于历史数据（2018-01~2026-07），历史表现不代表未来收益
2. 标的池高度集中于A股行业/主题ETF，板块间在系统性下跌中相关性极高，无法通过
   本池内部轮动实现真正的下行保护（已在V21-V26系列实验中反复验证）
3. V58方案的回撤（-25.2%）和最差单窗口（-12%量级）显著超过常规稳健型产品的
   风险预算，仅适合能承受较大波动、以短期超额收益为首要目标的资金
4. 量价确认信号基于历史成交额数据的统计规律，实盘中集合竞价、大宗交易等特殊
   成交可能扭曲短期量比信号，建议人工复核后再执行
